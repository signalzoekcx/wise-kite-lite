# wise-kite-lite

Mobile developer · Flutter and Dart · learning in public

拿来练手的小仓库

## 用法

```bash
cat data.txt | go run main.go
```

输出：

```

---

```

## 安装

```bash
git clone https://github.com/USER/wise-kite-lite.git
cd wise-kite-lite
go build ./...
```
